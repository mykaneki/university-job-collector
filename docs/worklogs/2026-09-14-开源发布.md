# 2026-09-14 开源发布

## 目标

在不公开本地采集数据、第三方招聘正文和联系方式的前提下，将项目以 Apache License 2.0 发布到 GitHub，并完成公开前安全检查。

## 实际操作

- 增加 Apache-2.0 许可证、贡献指南、安全政策、数据使用政策和第三方依赖许可说明。
- README 明确项目非官方属性、访问与合规边界、生成数据权利边界、CDP 安全限制和安全报告入口。
- `output/` 继续由 `.gitignore` 排除；仓库只加入完全合成的 Simple JSON 和不含路径、正文、联系方式、token、Raw 内容的脱敏运行汇总。
- 清理测试与文档中的真实招聘邮箱，提交身份改为 GitHub noreply 邮箱。
- 将远程主分支改写为单一干净根提交，清除旧提交内容和旧作者邮箱的可达历史。
- 将 GitHub 仓库切换为公开，并启用 Private Vulnerability Reporting。

## 结果

- 公开仓库：<https://github.com/mykaneki/university-job-collector>
- 许可证：Apache License 2.0。
- GitHub 仓库可见性为 `PUBLIC`，Private Vulnerability Reporting 状态为 `enabled: true`。
- 完整 Raw、Simple 输出、截图及本地诊断数据仍只保存在运行机器，不属于仓库发布内容。

## 验证

- 82 项单元测试通过。
- `compileall`、`pip check`、`git diff --check` 和两个公开示例的 JSON 语法检查通过。
- 全部可达 Git 引用中，旧 QQ 提交邮箱、已清理的真实招聘邮箱和本机绝对路径扫描结果为零。
- Git 跟踪文件中没有 `output/`、`.diagnostics/`、`.tmp/`、`.venv/`、`__pycache__`、`.pyc` 或 `.DS_Store`。

## 未完成项
