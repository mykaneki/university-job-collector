# 2026-09-09 可见 Chrome 受限高校补全

## 目标

对先前受 API 异常、TLS、WAF 或访问环境影响的中科大、川大、西南石油、重大、西工大、哈工程和兰大补全生产 collector；同时复核华南理工的公开访问权限。

## 实际操作

- 新增 `common.browser.ChromeCdpSession`，启动专用、可见的外部 Google Chrome，并由 Playwright 通过 CDP 接管。
- Chrome profile 持久化保留 WAF 建立的浏览器状态；使用排他锁和 owner PID/PGID 检查，残留进程未确认消失时 fail-closed。
- 信号、正常退出和 `atexit` 路径统一回收 Chrome；重复信号不会重入清理。
- 中科大在浏览器上下文中通过真实 XHR 分页；同时保存 document 响应、每次 XHR 原始响应和最终 rendered DOM，三者 metadata 分层记录。
- 川大、西南石油、重大、西工大和兰大使用真实 DOM 分页与详情解析；翻页异常不得静默当作正常结束。
- 西工大首次主响应可能为 412；原始 412 响应与挑战完成后的列表 DOM 分开保存，仅在真实列表 DOM 完整时继续。
- 哈工程改用正确的云就业列表 API。详情明确跳转 `/a/login`，所以保留公开列表数据、保存受限 Raw，JD 与投递方式留空。
- 兰大列表中的 3 条微信外链仍在列表 Raw 中保留，但不进入 Simple，避免违反“原始链接必须是高校详情页”的契约。
- 修复 percent-encoded `mailto:` 中的中文前缀被误识别为邮箱的问题；真实 Raw 回放确认只保留有效邮箱地址。
- 华南理工仍强制进入 CAS，不登录、不绕过。
