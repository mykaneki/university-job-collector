# 2026-09-08 上海高校采集器接入

## 目标

按导航顺序接入上海交通大学、复旦大学、同济大学、华东师范大学，遵守“一校一脚本”、Raw 无损保存、Simple JSON 严格六字段和公开权限边界。

## 实际操作

- 上海交通大学：验证完整列表 API 匿名请求返回 403；公开首页服务端渲染 8 条招聘公告，详情 JSON API 匿名可访问。实现首页列表 + JSON 详情的部分覆盖策略。
- 复旦大学：HTTP 和真实 Chrome 均返回 502；浏览器错误页明确说明当前 IPv6 出口未发布目的资源。实现失败响应 Raw 保存和显式运行失败，不将网络失败伪装成空结果。
- 同济大学：验证匿名列表 JSON API、筛选字典 API、详情 JSON API和 `pageNo` 分页。实现完整 JSON 采集器。
- 华东师范大学：验证完整列表 API 匿名请求返回 403；公开首页当前职位区块服务端渲染 6 条，详情 JSON API 匿名可访问。实现首页列表 + JSON 详情的部分覆盖策略。
- 更新学校配置、README、导航核验备注和解析器单元测试。
