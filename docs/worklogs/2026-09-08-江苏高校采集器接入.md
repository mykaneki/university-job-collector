# 2026-09-08 江苏高校采集器接入

## 目标

按导航顺序接入南京大学、东南大学、苏州大学，沿用统一时间窗、Raw 无损保存、Simple JSON 严格六字段和公开权限边界。

## 实际操作

- 南京大学：从 SPA 生产脚本定位匿名 `/api/career/job/recruitments` 列表和详情接口，以及公开配置字典接口。实测发现各页混有历史迁移记录，不能根据连续旧页提前停止，改为按 API `totalPages` 遍历。

- 更新学校配置、README、导航核验备注和南京大学确定性筛选测试。
