# 华中、华南高校采集器接入

## 目标

按“一校一脚本”原则接入华中科技大学、武汉大学、武汉理工大学、中南大学、湖南大学、中山大学、华南理工大学、厦门大学，并以 2026-09-06 00:00:00 至 2026-09-08 23:59:59 实际验证。

## 实际操作

- 用普通 HTTP 探测列表、翻页、筛选和详情，并用真实 Chromium DOM 核验 HUST、WUT、HNU、SYSU、XMU 列表及 SCUT CAS 跳转。
- WUT 通过真实页面网络请求确认公开前端固定使用 `login_user_id=1`、学校 ID 和 `/Wx/getselock`获取短期 lock，再调用 JSON API。这是未登录页面自身的公开协议，不是账号登录或权限绕过。
- CSU、SYSU、XMU 的列表/详情 HTML 使用 zlib + Base64 包装，生产脚本按页内固定规则确定性解包，无需浏览器。
- 单元测试新增 HUST/CSU 列表与包装 HTML 解码回归用例。
- 长测在 tmux `central_south_validation_20260909_v2` 中低频串行完成，日志为 `output/central_south_validation_20260909_v2.log`，完成后已关闭会话和所有浏览器标签页。
- WHU 详情超时策略调整为 5 秒、不重试后，经用户同意在 tmux `whu_revised_validation_20260909` 按原时间范围重跑，产物为 `output/20260909_whu_revised`，日志为 `output/whu_revised_validation_20260909.log`，完成后已关闭会话。

## 验证和异常

- WHU 列表 API 匿名正常。首次长测时公开详情 API 对 79 条持续无字节响应；将生产详情请求收敛为 5 秒、不重试后，二次原范围重跑获得 79/79 条有效 JSON。每条响应的标题和详情 URL 均与请求记录匹配；25 条有明确职位描述，78 条有明确邮箱或网申地址，源字段为空的 JD 保持空值。
- SCUT 的 `jyzx.scut.edu.cn` 真实页面跳转 `sso.scut.edu.cn/cas/login`，未进行登录、模拟账号或权限绕过。
- SYSU/XMU 传入站内 `keyword` 会跳统一认证，因此只保留公开的原生日期筛选，`position`/`keyword` 改为本地确定性标题筛选，不静默使用受限搜索。
