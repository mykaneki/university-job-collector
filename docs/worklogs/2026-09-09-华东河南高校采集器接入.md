# 华东与河南高校采集器接入

## 目标

接入浙江大学、中国科学技术大学、山东大学、中国海洋大学和郑州大学，并以 `2026-09-06 00:00:00` 至 `2026-09-08 23:59:59` 实际验收。

## 实际操作

- 在真实浏览器中核对各校列表、翻页和详情 DOM，再回退至能稳定生产的最低层级。
- 新增 `zju.py`、`ustc.py`、`sdu.py`、`ouc.py` 和 `zzu.py`。
- 为列表、详情和失败响应保存 Raw 与 metadata，为成功站点输出六字段 Simple JSON。
- 补充山大 HTML 列表解析、海大详情正文截取和 jqGrid 真实分页参数回归测试。

## 结果

- 浙大：JSON API，1 页 / 1 条，详情 1 成功。
- 中科大：公开 API 稳定返回 `error`，真实页面亦无列表数据，显式失败而不伪造空成功。
- 山大：GET HTML + Session，8 页 / 109 条，详情 109 成功。
- 海大：POST JSON + GET HTML，5 页 / 37 条，详情 37 成功。
- 郑大：页面数据必须浏览器渲染，Playwright 生产兜底，6 页 / 78 条，详情 78 成功。

海大首轮验收曾误用通用 `page/rows`，站点忽略后重复返回第 1 页。根因是没有使用站点 jqGrid 组件的真实参数名。经用户同意后改为 `queryModel.currentPage/queryModel.showCount`，并增加回归测试；旧目录 `output/20260909_east_batch` 中的 OUC 结果无效，有效结果在 `output/20260909_east_batch_ouc_fixed`。
