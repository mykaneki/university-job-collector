# 西南西北高校采集器接入

## 目标

接入电子科技大学、四川大学、西南石油大学、重庆大学、西安交通大学、西安电子科技大学、西北工业大学、长安大学，并以 2026-09-06 00:00:00 至 2026-09-08 23:59:59 做真实采集验证。

## 实际操作

- 对 8 个入口分别验证普通 HTTP、页面源码、公开接口和详情请求；需要确认渲染结果的站点使用真实 Chrome 核对 DOM 与 Network。
- 新增一校一文件的 collector，并将选择器、分页参数、筛选映射留在校级模块中。
- 生产长测在独立 tmux 会话 `ujc-west-batch` 执行，日志写入 `.diagnostics/west-batch.log`；完成后已清理会话。
- Raw 响应与 metadata 成对保存，失败站点保存可获得的错误响应或错误 metadata。
- 西交大列表偶有企业外链；Simple 的“原始链接”统一改为学校详情页 URL，企业外链不再替代来源页。

## 验证

- `python -m unittest discover -s tests -v`：29 项通过。
- 每个成功学校的 Simple JSON 均严格为六字段，所有时间均在目标范围内。
- 西交大 146 条“原始链接”均为 `job.xjtu.edu.cn/f/recruitmentinfo/show?recruitmentId=...`。
- 四川大学保存了 HTTP 483 完整 HTML 与 metadata，响应明确说明仅限校园网、校外需 WebVPN。
- 西北工业大学普通 HTTP 412，同时使用真实 Chrome 观察到公开列表；没有绕过 WAF 或登录。
- 长安大学列表没有发布时间，逐条访问详情后按详情发布时间过滤；连续两页正常记录均早于开始时间后停止。
