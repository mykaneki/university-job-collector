# 附录：高校就业网站栏目直达导航

更新至 2026年9月9日｜用于《国央企与事业单位招聘信息查找指南》

按学校查找所需栏目，点击完整网址即可前往对应页面。招聘信息、实习、宣讲会、双选会及相关专区分别列出。

本附录收录部分高校的就业栏目，不是各校全部栏目的完整目录。栏目中可能同时包含不同性质单位的招聘信息；单位性质、编制、报名时间和外校学生参加资格，以具体公告为准。部分页面需要登录，访问情况不确定的链接另有提示。

实际核验说明（2026年9月7日至9日）：

- 已为本附录所列 46 所高校逐校建立独立采集器。可访问学校以真实列表、分页、详情和 Raw 输出核验；受限学校保存真实失败响应并明确标注。单次 HTTP 200 或只出现页面外壳不再视为“可采”。
- **匿名 HTTP 可采**：普通 GET／POST、JSON API 或公开 Session 即可取得列表；是否能取详情会在学校条目中另行说明。
- **可见 Chrome/CDP 可采**：中科大、川大、西南石油、重大、西工大和兰大在普通 HTTP 下受 API、TLS 或 WAF 影响，但专用可见 Google Chrome profile 经 Playwright/CDP 接管后已取得真实列表。除当前只有一页数据的西南石油外，其余学校已完成多页翻页实测；公开详情按目标记录或探针验证。
- **部分覆盖**：天津大学、上海交大、华东师大只能取得公开首页的有限招聘记录，不代表完整列表。
- **明确受限**：华南理工公开入口强制进入 CAS；哈工程公开列表可采但详情进入学生登录；不绕过登录或权限。
- **当前网络仍受限**：复旦在当前 IPv6 出口返回 502；东南大学、苏州大学的 91job 分站被创宇盾规则 80001 间歇拦截。换网络后仍需重新核验，不能把失败永久归因于站点本身。
- 云就业模板常见栏目：`recruitmentinfoList.html?type=1` 招聘、`type=2` 实习、`recruitmentFairList.html` 宣讲、`bilateralchosefairList.html?type=4` 双选。24365 模板常见栏目：`/campus` 招聘简章、`/teachin` 宣讲、`/jobfair` 双选、`/job/search` 岗位；相似模板不代表请求协议完全相同。
- 所有生产结论均基于境内环境优先验证；需要浏览器的站点对出口、Chrome profile 和图形环境敏感，迁移机器后应复核。
